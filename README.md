# Proyecto BBVA 💳

Sistema bancario web desarrollado con React, Django y Supabase.

## Funcionalidades

- Login y registro(en postman sin frontend)
- Autenticación JWT
- Dashboard bancario
- Validaciones BBVA
- Integración React + Django

## Tecnologías

- React
- Vite
- Django REST Framework
- Supabase
- PostgreSQL
